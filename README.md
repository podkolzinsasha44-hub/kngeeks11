# Football GM

Футбольный менеджер для телефона и браузера — по образцу [NHL GM](https://github.com/podkolzinsasha44-hub/NHL), но про футбол. Вы — спортивный директор клуба сезона 2026/27: собираете состав, ведёте трансферы и переговоры, ставите одиннадцать на матч. Матчи играет честный движок, откалиброванный по реальным сезонам.

## Что внутри

- **6 523 реальных футболиста и 130 клубов на старте.** РПЛ (16 клубов), Первая лига (18), АПЛ, Ла Лига, Серия A, Бундеслига, Лига 1 — составы на сентябрь 2026, плюс игроки сборных ЧМ-2026 и сильнейшие игроки других лиг. Вымышленных игроков на старте нет; позже появляются только воспитанники академий — люди, которых в 2026 году ещё не было в футболе.
- **Реальные события.** РПЛ 2026/27 с «Родиной» и «Факелом» вместо вылетевших «Сочи» и «Пари НН», чемпион 2025/26 — «Зенит», Кубок России — «Спартак». Чемпион мира 2026 — Испания (серебро у Аргентины, бронза у Англии): призёры носят медали в профилях.
- **На поле выходит ваш состав.** Одиннадцать, которые вы выставили, — это одиннадцать, которые играют. Если кто-то из старта травмирован или дисквалифицирован, игра останавливается до матча и просит решить; без вашего решения штаб заменит только этого игрока, остальные останутся на местах.
- **Шансы — из самого движка.** Вероятности победы, ничьей и поражения — это 400 прогонов матчевого движка с вашими одиннадцатью и составом соперника. Прогноз сезона считается по той же формуле ожидаемых голов, что и матчи. Поменяли состав или тактику — цифры изменились.
- **Матчевый движок**: 90 минут по минутам, удары с xG, пенальти, карточки и удаления, травмы, усталость, пять замен, дополнительное время и серии пенальти в кубке. Движок не знает, каким клубом управляет человек.
- **Турниры**: чемпионаты семи лиг, Кубок России, переходные матчи РПЛ — Первая лига, повышение и вылет, чемпионат Европы 2028 и чемпионат мира 2030 со сборными из реальных игроков.
- **Рынок**: трансферные окна, цены клубов, встречные предложения, переговоры о контракте с агентом, свободные агенты, лимит на легионеров (12 в заявке и 7 на поле в 2026/27), зарплатный бюджет, предложения по вашим игрокам, сделки клубов между собой.
- **Карьера**: задачи и доверие совета директоров, увольнение и новые предложения, развитие и старение игроков, мораль, награды сезона, история.
- **Карточки игроков**: фото, рейтинг, позиция и характеристики; семь уровней редкости от бронзы до иконы — чем реже, тем богаче рамка, узор и анимация. На поле расстановки, скамейке и в резерве — те же карточки в маленьком виде.
- **Советы по трансферам**: вкладка «Советы» на рынке и карточка в офисе — кто усилит состав сейчас (и насколько), выгодные варианты, таланты на вырост и свободные агенты; учитываются бюджет, зарплаты, желание игрока перейти и лимит легионеров.
- **Версия для ПК**: в Chrome на компьютере — боковое меню, экраны в две колонки, окна вместо шторок; пробел — «Продолжить», 1–5 — разделы, Esc — назад.
- **PWA**: работает офлайн, ставится на экран «Домой», сохраняется в памяти устройства, есть экспорт и импорт сохранения.

## Как запустить

```bash
npm install
```

```bash
npm run dev
```

Откройте адрес из консоли в браузере. На iPhone: Safari → «Поделиться» → «На экран „Домой“».

Остальные команды:

```bash
npm test
```

```bash
npm run calibrate
```

```bash
npm run smoke -- 3 SPA
```

```bash
npm run build
```

`calibrate` играет шесть полных сезонов всех лиг и сравнивает итог с реальностью; `smoke` прогоняет несколько сезонов подряд без интерфейса.

## Обновить базу игроков

```bash
npm run data:fetch
```

```bash
npm run data:build
```

Первая команда скачивает снимок данных в `data/raw/` (в репозиторий он не попадает), вторая пересобирает `public/data/world.json`.

## Выкладка на Firebase Hosting

Ключ сервисного аккаунта Firebase лежит в секрете репозитория `FIREBASE_SERVICE_ACCOUNT` (Settings → Secrets and variables → Actions). Любой push в `main` или в рабочую ветку `claude/…` собирает игру, прогоняет тесты и выкладывает её; проект Firebase определяется по ключу. Адрес игры — `https://<id проекта>.web.app`, он же печатается в конце шага «Deploy to Firebase Hosting» во вкладке Actions. Pull request только собирается и тестируется.

В Firebase Console должен быть включён Hosting (Build → Hosting → Get started). Ключ никому не пересылайте и не добавляйте в репозиторий.

| Что | Источник | Лицензия |

| Кто в каком клубе, номера, амплуа, тренеры, стадионы | Википедия: страницы 130 клубов и сезонов 2026/27 | CC BY-SA 4.0 |
| Заявки и итоги ЧМ-2026 | Википедия | CC BY-SA 4.0 |
| Даты рождения, русские имена | Викиданные | CC0 |
| Биографии, оценки стоимости, сроки контрактов, статистика трёх сезонов | [transfermarkt-datasets](https://github.com/dcaribou/transfermarkt-datasets) | CC0 |

Рейтинги считает `scripts/build-world.mjs`: уровень — из оценки стоимости с поправкой на возраст, характеристики — из амплуа, роста и реальной статистики (голы, передачи, карточки, игровое время). Зарплаты — модель: реальные зарплаты не публикуются. У 294 игроков известен только год рождения, у 150 из них — и он неизвестен; в профиле возраст таких игроков помечен знаком «≈».

Фото игроков и эмблемы клубов загружаются с CDN Transfermarkt (портреты — по ссылкам из transfermarkt-datasets, id клубов — Wikidata, свойство P7223, список в `scripts/club-tm.mjs`), флаги — с flagcdn.com; всё кэшируется для офлайна. Если картинки нет, показывается силуэт в цветах клуба и значок, нарисованный из клубных цветов.

## Чего пока нет

- Еврокубков, национальных кубков других стран, вылета и повышения в зарубежных лигах.
- Режима «карьера игрока» и управления сборной (в NHL GM они есть).
- Аренды по инициативе пользователя; вмешательства в матч по ходу игры (замены делает штаб из названных вами запасных).
- Кубок России упрощён до сетки на выбывание из 32 клубов.
- Игроки, сменившие клуб летом 2026 на клуб вне семи лиг игры, в базу не попали, если их нет в заявках ЧМ-2026: их новый клуб неизвестен источникам.
